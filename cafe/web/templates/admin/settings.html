Персонал и курьеры

Роли — это группы в Telegram: кого добавили в группу, тот получает заказы и может нажимать кнопки; удалили из группы — доступа больше нет.

Заказы {% if cafe.staff_chat_id %}группа подключена{% endif %}

{% if cafe.staff_chat_id %}

Заказы приходят в группу персонала. Бариста и кассиров добавляйте в эту группу. Сменить группу — добавьте бота в другую и отправьте там /staff; вернуть заказы в личку — /staff боту в личные сообщения.

{% else %}

Сейчас заказы приходят администраторам в личные сообщения. Создайте группу «Заказы», добавьте туда бота и персонал, отправьте в группе /staff.

{% endif %}

Курьеры {% if cafe.courier_chat_id %}группа подключена{% endif %}

{% if cafe.courier_chat_id %}

Когда персонал нажимает «Передан курьеру», доставка приходит в группу курьеров: курьер жмёт «Беру», а у двери — «Доставлен». Отключить — /couriers боту в личные сообщения.

{% else %}

Сейчас «Доставлен» отмечает персонал. Если у вас свои курьеры — создайте группу «Курьеры», добавьте туда бота и курьеров, отправьте в группе /couriers.

{% endif %}

Финансы {% if cafe.finance_chat_id %}группа подключена{% endif %}

{% if cafe.finance_chat_id %}

В группу финансов приходят закрытые заказы (кто и как оплатил, кто из курьеров получил наличные), переводы со скриншотами и кнопкой «Оплата получена», а в конце рабочего дня — отчёт. /report в группе — отчёт за сегодня, /report yesterday — за вчера, /report 12h — за последние 12 часов.

{% else %}

Чтобы видеть деньги отдельно от потока заказов, создайте группу «Финансы» для себя и бухгалтера, добавьте бота и отправьте там /finance. Пока её нет, переводы подтверждает персонал, отчёт за день приходит администраторам, а /report работает в личке с ботом.

{% endif %}

Заказы, которые 6 часов висят в «Готов» или «Передан курьеру», закрываются сами.
