# limybot

White-label Telegram-бот для заказов в кафе и кофейнях: меню с фото → выбор добавок (размер, молоко, сиропы) →
корзина → самовывоз или доставка → заказ прилетает персоналу → клиенту приходит «готов».

Одна установка обслуживает много кафе: у каждого свой бот (свой токен), меню и настройки в базе.
Владелец кафе всё меняет сам в веб-админке с телефона — без паролей, вход по ссылке из бота.

## Запуск локально

Нужен [uv](https://docs.astral.sh/uv/getting-started/installation/) (Python он поставит сам).

**Windows:**
1. Создайте бота у [@BotFather](https://t.me/BotFather) (`/newbot`), скопируйте токен.
2. Подключите демо-кафе (в папке проекта, в `cmd`):
   ```
   run.cmd add demo --token 123456:ABC... --from clients\demo_coffee.json
   ```
   Команда проверит токен и напечатает ссылку `https://t.me/<бот>?start=join-...`.
3. Откройте эту ссылку в Telegram — вы администратор кафе.
4. Запустите всё: `run.cmd` (двойной клик). Работают все боты и админка на http://localhost:8000.
5. Напишите боту `/admin` — придёт ссылка входа в админку.

**Linux / macOS** — то же самое через `./run.sh`:
```bash
./run.sh add demo --token 123456:ABC... --from clients/demo_coffee.json
```
```bash
./run.sh
```

При первом запуске создаётся `.env` из `.env.example`. Там только адрес админки и путь к базе — токены и
настройки кафе хранятся в базе `data/limybot.db`.

## Подключение нового кафе (≈10 минут, без правки кода)

1. **Бот.** У @BotFather: `/newbot` → имя («Limy Coffee»), username (`limy_coffee_bot`) → токен.
   Там же можно поставить аватар (`/setuserpic`) и описание (`/setdescription`).
2. **Стартовое меню (необязательно).** Скопируйте `clients/demo_coffee.json` в `clients/<кафе>.json` и поправьте
   название, приветствие, часы, адрес, доставку, добавки и меню. Можно пропустить `--from`: кафе создастся пустым,
   и владелец заполнит всё в админке.
3. **Подключить:**
   ```bash
   ./run.sh add limy --token <ТОКЕН> --from clients/limy.json
   ```
   Запущенный процесс подхватит новое кафе сам в течение 15 секунд — перезапуск не нужен.
4. **Владелец.** Отправьте владельцу напечатанную ссылку-приглашение. Он открывает её → становится админом →
   пишет боту `/admin` → попадает в админку. Ссылка-приглашение одноразовая; новая — `./run.sh invite limy`
   или в админке «Настройки → Новая ссылка-приглашение» (так добавляют управляющих).
5. **Персонал.** Владелец создаёт группу в Telegram, добавляет туда бота и пишет в группе `/staff` — заказы
   начинают приходить в группу. Пока группы нет, заказы приходят админам в личку.

Другие команды: `./run.sh list` — все кафе, `./run.sh token limy <ТОКЕН>` — сменить токен (если владелец
перевыпустил его в @BotFather).

## Что умеет

- **Клиент:** меню по разделам, карточка позиции с фото и описанием, выбор добавок с доплатой (размер — один
  вариант, сиропы — несколько), корзина с ➕/➖, самовывоз или доставка (минимальная сумма, стоимость), адрес,
  телефон кнопкой, комментарий, подтверждение. Уведомления «принят», «готов», «отменён». Учитываются часы работы.
- **Персонал** (группа или админы в личке): карточка заказа с кнопками «Принять → Готов → Выдан» и «Отменить».
  Карточка обновляется, даже если статус сменили в админке.
- **Владелец в боте:** `/admin` — ссылка в админку, `/staff` — куда приходят заказы, `/stats` — заказы за сегодня.
- **Веб-админка:** заказы (обновляются сами каждые 30 с) со сменой статусов; меню — разделы, позиции, цены,
  описания, загрузка фото с телефона, стоп-лист, порядок; добавки; настройки кафе; администраторы.
- **Оплата:** пока «при получении». В заказе уже есть `payment_method` / `payment_status` под Payme и Click.

## На сервере

Процесс один: `uv run python -m cafe` (например, как systemd-сервис). Ботам нужен только исходящий интернет
(long polling). Админка слушает `WEB_HOST:WEB_PORT`; чтобы она открывалась с телефона, поставьте перед ней
nginx/Caddy с HTTPS, укажите `WEB_HOST=127.0.0.1` и `PUBLIC_URL=https://admin.ваш-домен.uz` в `.env`.
Бэкап — файл `data/limybot.db` и папка `data/photos/`.
