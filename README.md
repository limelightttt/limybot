# limybot

Telegram-бот заказов для кафе, кофеен, бургерных и любого общепита с самовывозом или доставкой. Гость открывает
в боте витрину (Telegram Mini App) в стиле заведения: меню с фото, добавки, корзина, самовывоз или доставка,
оплата при получении или переводом на карту. Заказ прилетает сотрудникам в их группу в Telegram, статусы — гостю.

## Как это устроено (за минуту)

- **Вы — оператор.** У вас одна программа limybot (на ноутбуке для демо, на сервере для клиентов). Ею вы управляете
  в **панели оператора** в браузере: подключаете заведения, видите, что у кого работает.
- **У каждого заведения свой бот** в Telegram (`@marrymefood_bot`, `@limy_coffee_bot`…). Боты создаются в
  @BotFather бесплатно; вы вставляете токен бота в панель — заведение подключено.
- **Владелец заведения** становится администратором по ссылке-приглашению, которую вы ему отправляете. Дальше он
  сам ведёт меню, цены, фото и заказы в **админке** (команда `/admin` в его боте).
- **Сотрудники** получают заказы в своей группе в Telegram: владелец просто добавляет туда бота.
- **Всё про заведения хранится в базе** `data/` (меню, админы, группа сотрудников, заказы). Её не удаляют и не
  переносят вручную — заведения удаляются и подключаются в панели.

## Запуск на своём компьютере (для демо)

Один раз:
1. Поставьте [uv](https://docs.astral.sh/uv/getting-started/installation/) (Python он поставит сам) и, чтобы
   витрина открывалась в Telegram, cloudflared: на Mac `brew install cloudflared`.
2. Скачайте проект: `git clone https://github.com/limelightttt/limybot && cd limybot`.

Каждый раз:
1. В папке проекта: `./run.sh` (Windows — `run.cmd`).
2. В окне появится рамка «limybot работает» — там ссылка в **панель оператора** и что с каждым заведением.
   Окно не закрывайте: пока оно открыто, боты работают. Остановить — Ctrl+C.
3. Откройте ссылку → «Подключить заведение».

https-адрес для витрины `./run.sh` получает сам (через cloudflared) — ничего вписывать в `.env` не нужно.
Адрес временный и при каждом запуске новый: в старых сообщениях бота кнопка «Открыть меню» перестаёт работать,
отправьте боту `/start` — придёт свежая.

## Подключить заведение

В панели оператора → «Подключить»:
1. **Бот.** В Telegram откройте @BotFather → `/newbot` → имя (как называется заведение) → адрес, оканчивающийся на
   `bot`. BotFather пришлёт токен вида `123456789:AAH…`. Для настоящего клиента лучше, чтобы бота создал сам
   владелец и прислал вам токен — тогда бот принадлежит ему.
2. **Меню.** Пустое (заполните в админке), готовый шаблон из списка или архив `.zip` с меню и фото.
3. «Подключить» — бот начинает работать сразу, без перезапуска.
4. **Владелец.** На странице заведения нажмите «Отправить в Telegram» — владелец откроет ссылку, нажмёт «Старт» и
   станет администратором. Ссылка срабатывает один раз; новую можно сделать там же.
5. **Сотрудники.** Владелец добавляет бота в группу сотрудников — бот сам начнёт присылать туда заказы. Удалили бота
   из группы — заказы снова идут владельцу в личку.

Хотите заполнить меню за владельца — на странице заведения «Открыть админку заведения».

На странице заведения также: «оплачено до» (после этой даты бот перестаёт принимать заказы), остановка приёма
заказов, смена бота (новый токен — меню и заказы сохраняются), удаление (бот освобождается, его можно подключить
заново с другим меню — так переделывают демо под другое заведение).

### Шаблон меню

Шаблон — папка с `.json` и фото, например `clients/demo_coffee.json`. В JSON: название, приветствие, часы, адрес,
доставка, добавки, меню и оформление: `"brand_color": "#FFC72C"`, `"app_theme": "dark"` (`auto` / `light` /
`dark`), `"logo": "logo.png"`, `"cover": "photos/cover.jpg"`, у позиции — `"photo": "photos/burger.jpg"`. Пути —
относительно JSON. Такую папку можно положить в `clients/private/<заведение>/` (она не попадает в git:
репозиторий публичный) — тогда она появится в списке шаблонов, или упаковать в zip и загрузить в панели.

## На сервере (для клиентов)

Нужны сервер с Docker и домен, который указывает на сервер. Персональные данные гостей по закону Узбекистана
хранятся на серверах в стране — берите сервер у узбекского хостинга.

```bash
git clone https://github.com/limelightttt/limybot && cd limybot
```
```bash
cp .env.example .env
```
Впишите в `.env` `DOMAIN=admin.ваш-домен.uz` и `SUPPORT=@ваш_контакт`, затем:
```bash
docker compose up -d
```
Caddy сам получит HTTPS-сертификат. Ссылка в панель оператора — в логе или командой:
```bash
docker compose exec app python -m cafe ops
```
Обновление: `git pull && docker compose up -d --build`. Данные (база, фото, бэкапы) — в `./data`.

## Если что-то не так

| Что видите | Что делать |
|---|---|
| «Порт 8000 занят» при `./run.sh` | limybot уже запущен в другом окне Терминала — закройте его (Ctrl+C) |
| «Нет https-адреса» в рамке или в панели | установите cloudflared и перезапустите `./run.sh` |
| В боте нет кнопки «Открыть меню» или она не открывается | отправьте боту `/start` — придёт свежая кнопка |
| Статус «Telegram не принял токен» | токен перевыпустили: новый — в @BotFather (`/mybots` → бот → API Token), вставьте в «Сменить бота» |
| Статус «Нет связи с Telegram» | нет интернета; бот подключится сам, когда связь появится |
| «Владелец ещё не подключился» | отправьте ему ссылку со страницы заведения |
| Заказы не приходят в группу | владелец должен добавить бота в группу сам; если добавил кто-то другой, админ пишет в группе `/staff` |
| Бот отвечает «Эта команда — для администраторов» | вы ещё не открыли ссылку-приглашение этого заведения |
| Нет ссылки в панель оператора | `./run.sh ops` |

## Командная строка

Всё основное есть в панели; команды — для сервера и скриптов (`./run.sh <команда>` или
`python -m cafe <команда>`): `ops` — ссылка в панель, `list` — заведения, `add --token … [--from шаблон.json]`,
`remove <имя>`, `token <имя> <токен>`, `invite <имя>`, `paid <имя> ГГГГ-ММ-ДД`, `disable` / `enable <имя>`,
`backup`.

## Что умеет

- **Гость (витрина):** меню по разделам в цветах заведения, карточка с добавками, корзина, самовывоз или доставка
  (минимальная сумма, стоимость), сохранённые телефон и адрес, комментарий, оплата при получении или переводом на
  карту. Русский и узбекский. Учитываются часы работы.
- **Гость (чат):** кнопка «Открыть меню», статусы заказа (свои для доставки и самовывоза), «Мои заказы» с повтором,
  отмена, пока заказ не принят, «Я перевёл», `/privacy`.
- **Сотрудники:** карточка заказа с кнопками самовывоз: Принять → Готовится → Готов → Выдан, доставка: Принять →
  Готовится → Передан курьеру → Доставлен, «Отменить», «Оплата получена».
- **Владелец:** `/admin` — админка: заказы, меню, фото, стоп-лист, добавки, часы, доставка, карта для переводов,
  оформление витрины, постер с QR-кодом, администраторы. `/stats` — заказы за сегодня.
- **Оператор:** панель с заведениями и их состоянием, подключение, подписка, остановка, смена бота, удаление,
  ежедневные бэкапы.

## Бэкапы

Раз в день limybot кладёт в `data/backups/limybot-<дата>.zip` базу и фото, хранит последние 14 дней. Чтобы
пережить смерть диска, копируйте папку с сервера, например `rclone sync data/backups remote:limybot` по cron.
Восстановление: остановить, распаковать архив в `data/` (`limybot.db` и `photos/`), запустить.
