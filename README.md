# limybot

White-label Telegram-бот заказов для кафе и кофеен. Гость открывает в боте витрину (Telegram Mini App): меню
с фото, выбор добавок (размер, молоко, сиропы), корзина, самовывоз или доставка, оплата при получении или
переводом на карту. Заказ прилетает персоналу в Telegram, статусы приходят гостю в чат.

Одна установка обслуживает много кафе: у каждого свой бот (свой токен), меню, оформление и настройки в базе.
Владелец кафе всё меняет сам в веб-админке с телефона — без паролей, вход по ссылке из бота.

## Что умеет

- **Гость (Mini App):** меню по разделам в цветах кафе (обложка, логотип, фирменный цвет), карточка с добавками,
  корзина, самовывоз или доставка (минимальная сумма, стоимость), сохранённые телефон и адрес, кнопка «Отправить
  номер из Telegram», комментарий, итог перед подтверждением, оплата при получении или переводом на карту.
  Русский и узбекский языки. Учитываются часы работы.
- **Гость (чат):** кнопка «Открыть меню», уведомления о статусах (свои для доставки и самовывоза), «Мои заказы»
  с повтором, отмена заказа, пока он не принят, «Я перевёл» для оплаты переводом, `/privacy`.
- **Персонал** (группа или админы в личке): карточка заказа с кнопками
  самовывоз: Принять → Готовится → Готов → Выдан, доставка: Принять → Готовится → Передан курьеру → Доставлен,
  «Отменить», «Оплата получена». Карточка обновляется, даже если статус сменили в админке или гость отменил заказ.
- **Курьеры** (своя группа, `/couriers`): доставка приходит в группу при «Передан курьеру», курьер жмёт «Беру»,
  у двери — «Доставлен». Забытые заказы закрываются сами через 6 часов.
- **Владелец в боте:** `/admin` — ссылка в админку, `/staff` — группа персонала, `/couriers` — группа
  курьеров, `/finance` — группа денег: чеки закрытых заказов, переводы со скриншотами, отчёт в конце рабочего дня;
  `/report` (`yesterday`, `12h`) — отчёт в любой момент.
- **Веб-админка:** заказы со сменой статусов и отметкой оплаты; меню — разделы, позиции, цены, фото, стоп-лист,
  порядок; добавки; настройки (часы, доставка, карта для переводов, оформление витрины); постер с QR-кодом для
  кассы и столов; администраторы.
- **Оператор (вы):** подключение кафе, подписка «оплачено до», отключение за неуплату, ежедневные бэкапы.

## На сервере (docker)

Нужны сервер с Docker и домен, который указывает на сервер. Персональные данные гостей по закону Узбекистана
хранятся на серверах в стране — берите сервер у узбекского хостинга.

```bash
git clone <репозиторий> limybot && cd limybot
cp .env.example .env        # впишите DOMAIN=admin.ваш-домен.uz и SUPPORT=@ваш_контакт
docker compose up -d        # бот + админка + Mini App; Caddy сам получит HTTPS-сертификат
```

Команды управления — внутри контейнера:
```bash
docker compose exec app python -m cafe add demo --token 123456:ABC... --from clients/demo_coffee.json
docker compose exec app python -m cafe list
```
Обновление: `git pull && docker compose up -d --build`. Данные (база, фото, бэкапы) лежат в `./data`.

## Локально

Нужен [uv](https://docs.astral.sh/uv/getting-started/installation/) (Python он поставит сам).
Windows: `run.cmd [аргументы]`, Linux/macOS: `./run.sh [аргументы]` — создают `.env`, ставят зависимости и
запускают `python -m cafe`.

1. Создайте бота у [@BotFather](https://t.me/BotFather) (`/newbot`), скопируйте токен.
2. `./run.sh add demo --token 123456:ABC... --from clients/demo_coffee.json` — напечатает ссылку-приглашение,
   откройте её в Telegram: вы администратор кафе.
3. Telegram открывает Mini App только по HTTPS. Поднимите туннель (например,
   `cloudflared tunnel --url http://localhost:8000`) и впишите выданный адрес в `.env`: `PUBLIC_URL=https://...`.
   Без туннеля бот и админка работают, но кнопки «Открыть меню» не будет.
4. `./run.sh` — запускает всех ботов и админку на http://localhost:8000. Витрину можно посмотреть в браузере:
   http://localhost:8000/app/demo (оформить заказ — только из Telegram).
5. Напишите боту `/admin` — придёт ссылка входа в админку.

## Подключение нового кафе (≈10 минут, без правки кода)

1. **Бот.** У @BotFather: `/newbot` → имя («Limy Coffee»), username (`limy_coffee_bot`) → токен.
   Там же аватар (`/setuserpic`) и описание (`/setdescription`). Кнопку «Меню» и команды бот настроит сам.
2. **Стартовое меню (необязательно).** Скопируйте `clients/demo_coffee.json` в `clients/<кафе>.json` и поправьте
   название, приветствие, часы, адрес, доставку, добавки и меню. Можно пропустить `--from`: кафе создастся пустым.
3. **Подключить:** `python -m cafe add limy --token <ТОКЕН> --from clients/limy.json`. Запущенный процесс подхватит
   кафе сам в течение 15 секунд.
4. **Подписка:** `python -m cafe paid limy 2026-12-01` — оплачено до этого дня включительно. Без даты кафе
   работает без ограничений.
5. **Владелец.** Отправьте ему ссылку-приглашение. Он открывает её → становится админом → пишет боту `/admin` →
   загружает логотип, обложку, фото меню, указывает карту для переводов. Новая ссылка — `python -m cafe invite limy`
   или в админке «Настройки → Новая ссылка-приглашение» (так добавляют управляющих).
6. **Персонал и курьеры.** Владелец создаёт группу, добавляет туда бота и пишет в группе `/staff` — заказы приходят в группу.
   Пока группы нет, заказы приходят админам в личку. Свои курьеры — отдельная группа с ботом и `/couriers`.
   Добавить или убрать человека — добавить или удалить его из группы.
7. **Продвижение.** Админка → «Продвижение» → распечатать постер с QR-кодом на кассу и столы.

Другие команды: `list` — все кафе и их подписка, `token limy <ТОКЕН>` — сменить токен, `disable limy` /
`enable limy` — остановить / возобновить приём заказов, `backup` — бэкап сейчас.

## Бэкапы

Раз в день процесс кладёт в `data/backups/limybot-<дата>.zip` базу и фото, хранит последние 14 дней.
Чтобы пережить смерть диска, копируйте папку с сервера, например `rclone sync data/backups remote:limybot`
по cron. Восстановление: остановить процесс, распаковать архив в `data/` (`limybot.db` и `photos/`), запустить.
