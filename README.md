# Cafe Bot

Telegram-бот для заказов в кафе и кофейне: меню → корзина → самовывоз или доставка → заказ прилетает персоналу →
клиенту приходит «готов». Один код на всех клиентов: всё, что отличается у кафе, лежит в `clients/<имя>.json`.

## Запуск (Windows)
1. Создайте бота у [@BotFather](https://t.me/BotFather) (`/newbot`), скопируйте токен.
2. `run.cmd`: при первом запуске создаст `.env` и откроет его. Впишите `BOT_TOKEN=...` и запустите `run.cmd` снова.
3. Напишите боту `/myid`, впишите свой id в `ADMIN_IDS=` в `.env`, перезапустите. Теперь заказы приходят вам.
4. Для персонала: создайте группу, добавьте туда бота, напишите в группе `/chatid`, впишите id в
   `STAFF_CHAT_ID=` и перезапустите. Теперь заказы идут в группу.

macOS/Linux: `cp .env.example .env`, заполнить, `uv run python -m cafe`.

## Что умеет
- **Клиент:** меню по разделам, корзина с ➕/➖, самовывоз или доставка (минимальная сумма и стоимость доставки),
  адрес, телефон кнопкой, комментарий, подтверждение. Уведомления: «принят», «готов», «отменён».
  Проверяются часы работы.
- **Персонал:** карточка заказа с кнопками «Принять → Готов → Выдан» и «Отменить». Устаревшие нажатия игнорируются.
- **Владелец** (`ADMIN_IDS`): `/admin` — меню с id позиций, `/price latte 32000` — цена, `/off latte` / `/on latte` —
  стоп-лист, `/stats` — заказы и выручка за сегодня.

## Новый клиент
Скопируйте `clients/demo_coffee.json` в `clients/<кафе>.json`: название, приветствие, часы, адрес, доставка, меню.
Укажите `CLIENT=<кафе>` и токен его бота в `.env`. Код не меняется.
